# ROS 2 and Simulation syllabus

Study these units in order during learning months 6. Units describe conceptual order, not additional calendar weeks. Reuse the monthly assignment and avoid starting a separate project for every topic.

| Unit | Topics and subtopics | Evidence of understanding |
| --- | --- | --- |
| 1 | Communication | Nodes, topics/services/actions, parameters, QoS, lifecycle concepts. |
| 2 | Robot description | URDF/Xacro, joints, tf2, robot_state_publisher, clock contract. |
| 3 | Gazebo integration | World, sensors, bridge, velocity interface, basic control integration. |
| 4 | Replay and diagnostics | rosbag2, sim time, stale messages, launch/restart and fault tests. |

## Completion standard

Submit the [core assignment](assignments/README.md), exercise reasoning, and a short note explaining one failure case. Apply the [curriculum assessment policy](../../docs/curriculum.md#assessment-policy). Reproduce a small case before increasing data, model, or robot complexity.
