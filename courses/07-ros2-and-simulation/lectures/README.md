# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Communication.** Read/watch selected material, then produce: Nodes, topics/services/actions, parameters, QoS, lifecycle concepts.
2. **Robot description.** Read/watch selected material, then produce: URDF/Xacro, joints, tf2, robot_state_publisher, clock contract.
3. **Gazebo integration.** Read/watch selected material, then produce: World, sensors, bridge, velocity interface, basic control integration.
4. **Replay and diagnostics.** Read/watch selected material, then produce: rosbag2, sim time, stale messages, launch/restart and fault tests.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
