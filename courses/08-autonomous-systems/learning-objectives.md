# Measurable learning objectives

By the end of this module, you should be able to:

- Evaluate estimated trajectories using independent ground truth and stated alignment.
- Explain localization, odometry, and SLAM as different estimation problems.
- Compare a planner against a known reference on a small map.
- Demonstrate mobile navigation and a bounded aerial simulation mission with fault handling.

Demonstrate these abilities through the [assignment](assignments/README.md) and one original explanation. Record assumptions and verification evidence; naming an algorithm without applying or evaluating it does not satisfy the objective.
