# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Estimation.** Read/watch selected material, then produce: EKF/particle filtering, wheel/IMU fusion, time alignment, observability.
2. **Mapping and odometry.** Read/watch selected material, then produce: VO, scan matching, SLAM, loop closure, map-based localization.
3. **Motion planning.** Read/watch selected material, then produce: A*/sampling-based concepts, collision inflation, trajectory tracking, Nav2.
4. **Aerial simulation.** Read/watch selected material, then produce: PX4 SITL, frames, offboard/mission control, command-loss response.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
