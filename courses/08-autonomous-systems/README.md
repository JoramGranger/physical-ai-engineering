# Autonomous Systems

Estimate state, map surroundings, plan motion, and evaluate mobile and aerial autonomy with failure cases.

**Learning months:** 7–8. **Status:** study specification; assignments and results are not completed.

## Prerequisites

Working ROS simulation, robot motion model, probability, matrix derivatives, and control basics.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [autonomous-mobile-robot project](../../projects/autonomous-mobile-robot/README.md).
