# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Problem formulation and splits.** Read/watch selected material, then produce: Feature/label contract and group/time separation.
2. **Linear and logistic models.** Read/watch selected material, then produce: Vectorized loss, regularization, optimization, and reference comparison.
3. **Alternative model families.** Read/watch selected material, then produce: Tree, margin-based classifier, PCA and clustering comparison on a small dataset.
4. **Evaluation and error analysis.** Read/watch selected material, then produce: Baseline table, class-wise errors, leakage audit, and frozen test protocol.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
