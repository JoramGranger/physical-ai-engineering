# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. For labels [0,0,0,0,1], calculate majority accuracy and the precision/recall of predicting no positives. State how undefined precision is handled.

2. Create repeated samples from three acquisition sessions. Compare random row splitting with holding out one session; explain why the former can overestimate deployment quality.

3. Construct a two-feature dataset with different scales. Compare unscaled and training-only standardized regularized logistic regression.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
