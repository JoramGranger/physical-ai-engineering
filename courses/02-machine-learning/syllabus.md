# Machine Learning syllabus

Study these units in order during learning months 1–2. Units describe conceptual order, not additional calendar weeks. Reuse the monthly assignment and avoid starting a separate project for every topic.

| Unit | Topics and subtopics | Evidence of understanding |
| --- | --- | --- |
| 1 | Problem formulation and splits | Feature/label contract and group/time separation. |
| 2 | Linear and logistic models | Vectorized loss, regularization, optimization, and reference comparison. |
| 3 | Alternative model families | Tree, margin-based classifier, PCA and clustering comparison on a small dataset. |
| 4 | Evaluation and error analysis | Baseline table, class-wise errors, leakage audit, and frozen test protocol. |

## Completion standard

Submit the [core assignment](assignments/README.md), exercise reasoning, and a short note explaining one failure case. Apply the [curriculum assessment policy](../../docs/curriculum.md#assessment-policy). Reproduce a small case before increasing data, model, or robot complexity.
