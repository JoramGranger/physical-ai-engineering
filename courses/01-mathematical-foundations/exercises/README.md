# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. Let X have rows [1,1], [1,2], [1,3] and y = [1,2,2]. Solve least squares without explicitly computing an inverse; report the residual and matrix rank. Duplicate a column and explain the changed solution set.

2. For f(w) = mean((Xw-y)^2), derive the gradient. Compare analytic and central-difference results for h from 1e-2 to 1e-7 in float64; explain the error curve.

3. A sensor has true-positive rate 0.9 and false-positive rate 0.1. For event prevalence 0.01, compute the posterior after a positive observation and explain the base-rate effect.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
