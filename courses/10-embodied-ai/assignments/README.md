# Assignment: Scripted, imitation, and RL policy comparison

**Status:** specification. Implementation and measured results are future work.

Complete the Month 10 small simulated-task comparison with a shared environment and bounded compute. Treat OpenVLA as a paper/interface study unless compatible hardware and data are available.

## Verification

- Evaluate on held-out episodes and initial states; report return and task success separately.
- Use at least three seeds for cheap baselines, enforce action limits, and log unsuccessful learning honestly.

Provide the derivation/design, runnable command or clearly scoped implementation plan, configuration/version manifest, evaluation evidence, and one failure analysis. Link external artifacts by hash/location rather than committing large files. Use the [experiment record](../../../experiments/TEMPLATE.md).
