# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. Compute two Bellman backups for a two-state MDP with explicitly chosen transition/reward values and discount 0.9.

2. Create training and held-out initial-state ranges; explain why random splitting of frames from one demonstration leaks information.

3. Specify a seven-dimensional example action vector, including each component's unit, frame, range, rate, and whether it is absolute or incremental.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
