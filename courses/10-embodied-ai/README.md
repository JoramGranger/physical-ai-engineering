# Embodied AI

Study embodied policies through small repeatable experiments and a critical VLM/VLA interface analysis.

**Learning months:** 10. **Status:** study specification; assignments and results are not completed.

## Prerequisites

Neural-network training, robot task/observation interfaces, and a deterministic simulated controller.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [vision-guided-manipulation project](../../projects/vision-guided-manipulation/README.md).
