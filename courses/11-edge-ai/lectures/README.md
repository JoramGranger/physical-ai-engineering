# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Reference contracts.** Read/watch selected material, then produce: Inputs, preprocessing, versions, output semantics, test fixtures.
2. **Export and parity.** Read/watch selected material, then produce: ONNX, opsets, shape constraints, numerical/task-level comparison.
3. **Optimization.** Read/watch selected material, then produce: Precision, representative calibration, TensorRT compatibility, memory/power/thermal behavior.
4. **Deployment and operation.** Read/watch selected material, then produce: Serving queues, health, observability, artifact promotion, rollback and fallback.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
