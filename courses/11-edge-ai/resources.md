# Resources and reading selections

- [PyTorch tutorials](https://docs.pytorch.org/tutorials/) — Reference training/export implementation guidance.
- [ONNX documentation](https://onnx.ai/onnx/) — Model interchange and graph validation.
- [TensorRT documentation](https://docs.nvidia.com/deeplearning/tensorrt/latest/) — Target-specific acceleration and support matrix.
- [Stanford CS231n, 2025](https://cs231n.stanford.edu/2025/) — Revisit architecture tradeoffs for visual models.
- [Deep Learning](https://www.deeplearningbook.org/) — Numerical/learning tradeoff reference.
