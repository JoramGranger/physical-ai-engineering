# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. Separate a latency budget into capture, decode, preprocess, inference, postprocess, queue, and communication. State which intervals overlap.

2. Compare original/exported outputs on identical synthetic inputs and near-threshold real examples; choose tolerances before testing.

3. Explain why a TensorRT engine built for one device/runtime combination cannot be assumed portable to every target.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
