# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. For a two-link planar arm with lengths 1 m and 0.5 m, calculate end-effector position at joint angles (0,0) and (π/2,0). Identify a singular configuration.

2. Derive differential-drive body velocity from left/right wheel angular velocities, radius r, and track width b. Check equal-speed and opposite-speed cases.

3. Simulate PID with an actuator clamp; compare integral accumulation with and without anti-windup. Repeat with twice the timestep.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
