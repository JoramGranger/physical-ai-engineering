# Robotics Engineering

Connect mechanics, estimation interfaces, and discrete controllers to constrained robot motion.

**Learning months:** 5, with capstone reuse. **Status:** study specification; assignments and results are not completed.

## Prerequisites

Rigid transforms, derivatives/Jacobians, ODE concepts; prior programming experience is assumed.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [robotic-arm project](../../projects/robotic-arm/README.md).
