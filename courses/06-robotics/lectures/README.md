# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Kinematics.** Read/watch selected material, then produce: Frames, forward/inverse kinematics, Jacobians, workspace, singularities.
2. **Dynamics and actuation.** Read/watch selected material, then produce: Joint torques, simplified motor models, friction, saturation.
3. **Control.** Read/watch selected material, then produce: PID, timestep selection, anti-windup, disturbances, trajectories.
4. **C++ and embedded interfaces.** Read/watch selected material, then produce: RAII, build tooling, timing, encoders, watchdog, telemetry.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
