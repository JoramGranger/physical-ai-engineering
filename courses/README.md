# Course guide

These eleven modules support the [monthly curriculum](../docs/curriculum.md). They are not eleven concurrent university courses. Each assignment is a component of the existing monthly project; do not add its hours twice.

| Course | Learning months | Main output |
| --- | --- | --- |
| [Mathematical Foundations](01-mathematical-foundations/README.md) | 1, with refreshers in 4–10 | Gradient and conditioning audit |
| [Machine Learning](02-machine-learning/README.md) | 1–2 | Leakage-free classical baseline |
| [Deep Learning](03-deep-learning/README.md) | 2 | Reproducible classifier training |
| [Computer Vision](04-computer-vision/README.md) | 3 | Detection, segmentation, and tracking audit |
| [3D Perception and Spatial Intelligence](05-3d-perception/README.md) | 4 | Calibrated reconstruction baseline |
| [Robotics Engineering](06-robotics/README.md) | 5, with capstone reuse | Modeled robot and bounded controller |
| [ROS 2 and Simulation](07-ros2-and-simulation/README.md) | 6 | Reproducible simulated robot |
| [Autonomous Systems](08-autonomous-systems/README.md) | 7–8 | Estimation and mission evaluation |
| [Agentic AI](09-agentic-ai/README.md) | 9 | Bounded simulated task planner |
| [Embodied AI](10-embodied-ai/README.md) | 10 | Scripted, imitation, and RL policy comparison |
| [Edge AI and Deployment](11-edge-ai/README.md) | Parallel throughout; focused integration in 11–12 | Measured deployment candidate |

Every course has a syllabus, measurable objectives, resources, and focused exercise/lecture/assignment/note directories. Reading selections remain bounded; new lessons should be added only when they clarify an observed learning gap.
