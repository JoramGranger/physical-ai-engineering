# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Images as measurements.** Read/watch selected material, then produce: Color spaces, convolution, filtering, sampling, morphology.
2. **Detection and segmentation.** Read/watch selected material, then produce: Label contracts, resizing, masks, IoU, confidence thresholds, NMS.
3. **Temporal association.** Read/watch selected material, then produce: Prediction, assignment, lifecycle, occlusion and ID switches.
4. **Pipeline evaluation.** Read/watch selected material, then produce: Recording-separated test, latency stages, difficult-case analysis.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
