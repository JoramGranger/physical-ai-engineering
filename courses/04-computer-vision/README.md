# Computer Vision

Build measured image/video perception rather than relying on attractive demonstration frames.

**Learning months:** 3. **Status:** study specification; assignments and results are not completed.

## Prerequisites

A working classifier baseline; array geometry and CNN training concepts.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [object-detection-tracking project](../../projects/object-detection-tracking/README.md).
