# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. Resize a 640×480 image to 320×240 and transform a box [100,80,300,200]. Invert the transform and compare coordinates; repeat with letterboxing.

2. Calculate IoU for axis-aligned boxes [0,0,2,2] and [1,1,3,3] using continuous coordinates. Document how pixel-inclusive conventions differ.

3. Create two crossing synthetic tracks with one missed frame; compare nearest-neighbor association to prediction plus global assignment.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
