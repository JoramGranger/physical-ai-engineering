# Computer Vision syllabus

Study these units in order during learning months 3. Units describe conceptual order, not additional calendar weeks. Reuse the monthly assignment and avoid starting a separate project for every topic.

| Unit | Topics and subtopics | Evidence of understanding |
| --- | --- | --- |
| 1 | Images as measurements | Color spaces, convolution, filtering, sampling, morphology. |
| 2 | Detection and segmentation | Label contracts, resizing, masks, IoU, confidence thresholds, NMS. |
| 3 | Temporal association | Prediction, assignment, lifecycle, occlusion and ID switches. |
| 4 | Pipeline evaluation | Recording-separated test, latency stages, difficult-case analysis. |

## Completion standard

Submit the [core assignment](assignments/README.md), exercise reasoning, and a short note explaining one failure case. Apply the [curriculum assessment policy](../../docs/curriculum.md#assessment-policy). Reproduce a small case before increasing data, model, or robot complexity.
