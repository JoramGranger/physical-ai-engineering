# Deep Learning

Build a debuggable PyTorch training workflow and understand why training succeeds or fails.

**Learning months:** 2. **Status:** study specification; assignments and results are not completed.

## Prerequisites

Regression/classification baseline and gradient checks; familiarity with NumPy-style tensor shapes.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [image-classification project](../../projects/image-classification/README.md).
