# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Differentiation and network structure.** Read/watch selected material, then produce: Two-layer backpropagation and autograd comparison.
2. **Training mechanics.** Read/watch selected material, then produce: Data loader, optimizer, train/eval semantics, stable cross-entropy.
3. **CNNs and transfer learning.** Read/watch selected material, then produce: Small CNN versus pretrained feature baseline.
4. **Reproducibility and diagnosis.** Read/watch selected material, then produce: Tiny-batch fit, one ablation, resume test, error slices.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
