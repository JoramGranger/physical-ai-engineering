# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. For a two-layer network, list activation and gradient shapes for batch size 4, input dimension 3, hidden dimension 5, and 2 classes.

2. Explain why applying softmax before a cross-entropy API that expects logits changes the intended computation. Verify the installed API contract.

3. Train on a fixed tiny clean batch; compare normal labels, shuffled labels, disabled gradients, and train/eval mistakes.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
