# Deep Learning syllabus

Study these units in order during learning months 2. Units describe conceptual order, not additional calendar weeks. Reuse the monthly assignment and avoid starting a separate project for every topic.

| Unit | Topics and subtopics | Evidence of understanding |
| --- | --- | --- |
| 1 | Differentiation and network structure | Two-layer backpropagation and autograd comparison. |
| 2 | Training mechanics | Data loader, optimizer, train/eval semantics, stable cross-entropy. |
| 3 | CNNs and transfer learning | Small CNN versus pretrained feature baseline. |
| 4 | Reproducibility and diagnosis | Tiny-batch fit, one ablation, resume test, error slices. |

## Completion standard

Submit the [core assignment](assignments/README.md), exercise reasoning, and a short note explaining one failure case. Apply the [curriculum assessment policy](../../docs/curriculum.md#assessment-policy). Reproduce a small case before increasing data, model, or robot complexity.
