# 3D Perception and Spatial Intelligence

Turn calibrated images into spatial estimates with explicit frames, scale, and uncertainty.

**Learning months:** 4. **Status:** study specification; assignments and results are not completed.

## Prerequisites

Image processing, linear algebra/SVD, homogeneous coordinates, and basic camera data handling.

## How to study

Follow the ordered units in the syllabus, derive the key result before implementing it, and use the exercise set to expose mistakes on small examples. Complete the core assignment as part of the [monthly curriculum](../../docs/curriculum.md); share its data and evidence with the [3d-reconstruction project](../../projects/3d-reconstruction/README.md).
