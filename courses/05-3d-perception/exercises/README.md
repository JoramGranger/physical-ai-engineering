# Focused exercise set

Work these examples before the main assignment. State units/shapes and derive an expected result before running code.

1. With rectified focal length 400 pixels, baseline 0.1 m, and disparity 20 pixels, compute depth. Repeat for disparity ±1 pixel and explain the asymmetry.

2. Construct T_A_B and T_B_C for simple translations and a quarter-turn rotation; verify composition on a known point and invert it.

3. Triangulate noise-free synthetic correspondences; then reduce baseline toward zero and plot the change in depth stability.

Submit concise reasoning plus a numerical check where appropriate. Explain discrepancies and one limiting/degenerate case; do not use a plot alone as verification. These exercises feed the [core assignment](../assignments/README.md).
