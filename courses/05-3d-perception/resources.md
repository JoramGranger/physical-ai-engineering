# Resources and reading selections

- [Stanford CS231A](https://web.stanford.edu/class/cs231a/) — Primary geometric vision selections.
- [MIT 6.801 Machine Vision](https://ocw.mit.edu/courses/6-801-machine-vision-fall-2020/) — Image-formation background.
- [Multiple View Geometry](https://www.robots.ox.ac.uk/~vgg/hzbook/) — Projective and multiple-view geometry.
- [Szeliski — Computer Vision](https://szeliski.org/Book/) — Practical reconstruction reference.
- [OpenCV 4.x](https://docs.opencv.org/4.x/) — Calibration and geometry implementation APIs.

Select the syllabus topics within these sources; the labels are our study route, not asserted lecture titles or numbers. Use the [central verification register](../../docs/resources.md) for the 2026-11-23 access review, restricted-video caveats, and book availability.
