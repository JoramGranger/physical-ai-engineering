# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Camera models.** Read/watch selected material, then produce: Intrinsics, extrinsics, lens distortion, calibration views.
2. **Two-view geometry.** Read/watch selected material, then produce: Correspondence, epipolar constraints, robust estimation, triangulation.
3. **Depth and reconstruction.** Read/watch selected material, then produce: Stereo disparity, RGB-D backprojection, point clouds, scale ambiguity.
4. **Alignment and error.** Read/watch selected material, then produce: ICP assumptions, bundle-adjustment objective, residuals and degeneracy.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
