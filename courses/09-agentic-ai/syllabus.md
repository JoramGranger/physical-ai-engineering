# Agentic AI syllabus

Study these units in order during learning months 9. Units describe conceptual order, not additional calendar weeks. Reuse the monthly assignment and avoid starting a separate project for every topic.

| Unit | Topics and subtopics | Evidence of understanding |
| --- | --- | --- |
| 1 | Language-model systems | Token/context budgets, structured output, model configuration and reproducibility. |
| 2 | Retrieval | Chunking, embeddings, evidence IDs, retrieval versus answer evaluation. |
| 3 | Tool orchestration | Typed schemas, pre/postconditions, idempotency, retries, bounded state machine. |
| 4 | Task evaluation | Scripted baseline, invalid requests, injection/staleness tests, traces and budgets. |

## Completion standard

Submit the [core assignment](assignments/README.md), exercise reasoning, and a short note explaining one failure case. Apply the [curriculum assessment policy](../../docs/curriculum.md#assessment-policy). Reproduce a small case before increasing data, model, or robot complexity.
