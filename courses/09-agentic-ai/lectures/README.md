# Lecture study route

Use the [official sources](../resources.md) in this order. This is an original topic guide; no local lecture recordings or copied decks are supplied.

1. **Language-model systems.** Read/watch selected material, then produce: Token/context budgets, structured output, model configuration and reproducibility.
2. **Retrieval.** Read/watch selected material, then produce: Chunking, embeddings, evidence IDs, retrieval versus answer evaluation.
3. **Tool orchestration.** Read/watch selected material, then produce: Typed schemas, pre/postconditions, idempotency, retries, bounded state machine.
4. **Task evaluation.** Read/watch selected material, then produce: Scripted baseline, invalid requests, injection/staleness tests, traces and budgets.

Spend the curriculum's reading allocation on the topic you cannot yet explain or verify. After a session, write the key assumption and a question answered by the next exercise. Do not infer access to a restricted recording from a public course homepage.
