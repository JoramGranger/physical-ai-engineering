# Experiment: descriptive title

**Status:** planned / running / complete / inconclusive. Replace these fields when a real run begins.

## Question and hypothesis

State the decision this experiment informs and a falsifiable prediction. Define the baseline, changed variable, controlled conditions, and acceptance threshold before measurement.

## Provenance and environment

| Field | Value to record |
| --- | --- |
| Run ID / date / timezone | Unique ID and actual acquisition time |
| Source/configuration | Commit, dirty-tree status, exact config path/hash |
| Data / model / calibration / scene | Source, release, license, hash, external location |
| Splits / seeds | Acquisition groups, episode/session separation, RNG state |
| Hardware / runtime | CPU/GPU/device, driver, libraries, OS, container digest |
| Frames / units / clocks | Transform directions and synchronization assumptions |
| Commands / budget | Setup, run, evaluate commands, wall/compute budget |

## Method

Describe sample count, warmup, timing boundaries, repetitions, fault cases, metric definitions, uncertainty method, and exclusions fixed in advance. Distinguish simulated, replay, bench, and physical observations.

## Results

Populate only after a run. Include raw-artifact hashes/locations, baseline comparison, denominators, units, variation, failed runs, and protocol deviations. Do not insert illustrative numbers that could be mistaken for observations.

## Interpretation and limitations

Explain whether evidence supports the hypothesis, alternative explanations, untested conditions, and measurement limitations. Separate observation from inference.

## Decision and reproduction

State adopt / reject / investigate, the reason, and the next bounded action. Give a minimal reproduction command and artifact acquisition path; link the owning project and journal entry.
