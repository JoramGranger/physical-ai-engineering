# Assets and publication provenance

Store small original diagrams, compressed figures, and publication illustrations here when created. No project screenshots, hardware photographs, or result videos exist at initialization.

Use a descriptive topic filename and link it from the owning document. For each third-party or generated asset, record creator/source, license or permission, creation/download date, modifications, and intended use. Keep an adjacent provenance note if the document caption cannot carry that information.

Do not redistribute book PDFs, course slides, datasets, model weights, or restricted lecture material. Use source links instead. Large recordings, point clouds, and model artifacts belong in external storage with checksums referenced from an [experiment record](../experiments/TEMPLATE.md).

Label simulation versus physical media and include the experiment ID. An illustrative diagram or mockup must not be presented as an implemented system or measured outcome.
